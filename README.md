# Linux CLI Utilities

A collection of Linux command-line utilities
implemented in C.

## Programs

- my_cat — Display file contents
- my_head — Print the beginning of a file
- my_tail — Print the end of a file
- my_wc — Count lines, words, and bytes
- my_toupper_file — Convert file contents to uppercase

## Technologies

- C Programming
- Linux System Calls
- File Descriptors
- File I/O
- GCC
